# 캘린더 날짜 미리보기 패널 설계

- 작성일: 2026-08-20
- 상태: 승인됨
- 관계: `2026-08-06-core-ux-flow-design.md` 2절(정보 구조)의 "캘린더: 날짜별 체크인과 회고 탐색" 역할을 캘린더 탭 자체에서 보강하는 후속 UX 설계. 일별 상세 화면(`DailyDetailScreen`)의 역할과 범위는 바꾸지 않는다.
- 우선순위: 이 문서와 기존 문서가 충돌하지 않는다 — 캘린더 탭의 신규 상호작용만 추가한다.

## 1. 배경

캘린더 탭은 월 그리드와 하단 범례·요약(`b5d5cde`에서 추가)까지 넣어도 화면 하단에 상당한 빈 공간이 남는다. 날짜를 눌러야만 정보를 확인할 수 있는 현재 흐름은, 여러 날짜를 훑어보고 싶을 때마다 전체 화면 전환을 요구한다. 이 설계는 그 빈 공간을 날짜 미리보기 패널로 채워 두 문제를 함께 해결한다 — 여백을 기능으로 바꾸고, 날짜 탐색 시 화면 전환 없이 훑어볼 수 있게 한다.

## 2. 새로운 동작

```text
캘린더 탭 진입
  ↓
보고 있는 달에 오늘 날짜가 있으면 오늘을 기본 선택
  (없으면 선택 없음 — 기존과 동일하게 범례·요약만 표시)
  ↓
날짜 셀 탭
  ↓
셀이 선택 상태로 강조 + 그리드 아래에 해당 날짜 미리보기 패널 표시
  ├─ 체크인이 있으면: 날짜, 체크인 개수, 체크인 시각 목록, "자세히 보기"
  └─ 체크인이 없으면: "이날은 남겨진 발자국이 없어요", "자세히 보기"
        ↓
     "자세히 보기" → 일별 상세 화면(`/day/[date]`)으로 이동 (기존 동작 그대로)
```

이전/다음 달로 이동하면 선택은 초기화된다 — 새 달에는 선택된 날짜가 보이지 않으므로 미리보기를 유지할 근거가 없다.

## 3. 화면 구성

기존 레이아웃(헤더 → 요일 행 → 월 그리드 → 범례·요약)은 그대로 유지하고, 그 아래에 미리보기 패널을 추가한다.

- 선택된 날짜 셀은 배경을 채워 강조한다(지도 핀·타임라인 슬롯 선택과 같은 시각적 언어).
- 범례("체크인 기록이 있는 날")와 "이번 달 체크인 N일" 요약은 선택 여부와 무관하게 항상 보인다 — 미리보기는 그 아래에 추가되는 영역이다.
- 미리보기 패널:
  - 날짜와 체크인 개수: 예) `8월 20일`, `체크인 2개 · 00:55, 14:32`
  - 체크인이 없는 날: `이날은 남겨진 발자국이 없어요`
  - `자세히 보기 →` 버튼: 항상 표시(체크인이 없어도 회고 본문은 작성할 수 있으므로 — `2026-08-06-core-ux-flow-design.md` 5.2절)

## 4. 데이터

`CheckInRepository.listByLocalDay(localDate, timezone)`을 그대로 재사용한다 — 일별 상세 화면과 동일한 메서드이며, 새 저장소 메서드는 필요 없다. 날짜 선택 시 해당 날짜로 한 번 조회하고, 다른 날짜를 선택하면 새로 조회한다(이전 결과는 버린다).

## 5. 상태

- `selectedDate: string | null` — 초기값은 오늘이 보이는 달을 보고 있으면 오늘의 로컬 날짜, 아니면 `null`.
- 월 이동(`goToPreviousMonth`/`goToNextMonth`) 시 `selectedDate`를 `null`로 초기화한다.
- 미리보기 데이터 로딩 상태는 일별 상세 화면과 같은 패턴(로딩/완료/오류)을 따르되, 이 패널에서는 로딩 중에도 레이아웃이 크게 흔들리지 않도록 이전 선택의 패널 높이를 유지한다.

## 6. 오류 처리

| 상황 | 처리 |
|---|---|
| 미리보기 조회 실패 | 패널에 "불러오지 못했어요" 텍스트만 표시, 그리드·범례·요약은 영향 없음 |
| 오늘이 포함된 달인데 오늘 조회 실패 | 선택 없음 상태로 폴백(기존 화면과 동일하게 보임) |

## 7. 범위

### 포함

- 날짜 셀 탭 시 그리드 아래 미리보기 패널 표시
- 진입 시 오늘 날짜 기본 선택(오늘이 보이는 달일 때)
- 월 이동 시 선택 초기화
- "자세히 보기"로 일별 상세 이동

### 제외

- 패널 안에서의 회고 작성·사진 확인(일별 상세 화면의 역할 그대로 유지)
- 여러 날짜 동시 선택·범위 선택
- 패널 애니메이션 세부 사양(구현 시 기존 모션 토큰인 `short(150–250ms)` 사용)

## 8. 테스트 초점

- 오늘이 보이는 달 진입 시 오늘이 기본 선택되는지, 다른 달을 보고 있을 때는 선택되지 않는지
- 날짜 탭 시 미리보기 패널이 올바른 체크인 개수·시각을 보여주는지
- 체크인이 없는 날 선택 시 빈 상태 문구와 "자세히 보기"가 함께 보이는지
- 월 이동 시 선택과 미리보기가 초기화되는지
- "자세히 보기" 탭 시 올바른 날짜로 이동하는지
- 미리보기 조회 실패가 그리드·범례·요약 렌더링에 영향을 주지 않는지
